Veritas Technologies

Scalable Enterprise Sizing Tools

Role UX Designer
Timeline Mar – Aug 2023
Status Shipped
Cybersecurity B2B Enterprise Platform Design Design Systems Hybrid Cloud

Veritas' legacy sizing process required sales engineers to manually configure complex appliance configurations across dozens of variables — a slow, error-prone process that bottlenecked enterprise deals. This project introduced a scalable web-based sizing framework that replaced those manual workflows entirely.

I designed the end-to-end experience: a multi-step configuration wizard, real-time validation, results visualization, and exportable output for sales proposals. The framework now supports Veritas' full hybrid cloud portfolio and is used by field engineers across North America, EMEA, and APAC.
